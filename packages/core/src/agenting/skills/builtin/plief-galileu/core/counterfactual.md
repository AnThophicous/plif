# Counterfactual Engine

Mechanized triggers (run when condition holds; not judgment-gated):

```text
T1 an option INVALIDATES/depends on a dependency that could disappear
T2 an assumption marked impact_if_false=critical supports the leading option
T3 scale premise ×10 plausible in stated context
T4 compared feature/set exists today but disappearance is cheap to imagine
T5 reversibility optimization requested ("what if we optimize for reverting?")
```

Template per run: state the variant ("what if option B?" / "assumption X false?") → trace affected nodes via graph edges → name cheapest probe that would discriminate → record as `consequence` node linked IMPLIES/CONTRADICTS where appropriate.

Counterfactual output is short, specific, and falsifiable — no generic risk laundry lists.
