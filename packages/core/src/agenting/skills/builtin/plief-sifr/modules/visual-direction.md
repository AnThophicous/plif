# Visual Direction — design theses, not theme swaps

Used when structure is settled but direction is genuinely open, or user explicitly explores directions. Freezes into `design-dna.json` via DesignDNA schema.

## Rules

1. Freeze common truth: all options solve the SAME product problem (same IA, content, states, viewports, a11y obligations, invariants).
2. Derive only dimensions with real freedom (restrained↔expressive, editorial↔app-like, dense↔spacious, technical↔human, geometric↔organic...); coordinate them into coherent THESIS relationships, never sampled at random coordinates.
3. Generate 2–4 real theses; different fonts on identical layout = one option. First option should be the strongest conservative fit; every wider option stays product-credible. No strawman option to flatter a favorite.
4. Distinctness test: reviewer could identify the thesis after logo removal/accent neutralization/same content/grayscale.
5. Select language families from product pressure using `references/atlas.md` (single canonical visual vocabulary source; hybrid allowed only with one obvious dominant).
6. Signature move: exactly one memorable relationship per option, improving hierarchy/comprehension/identity/navigation/spatial continuity/completion feedback. Every component being a signature means none is.
7. Risk analysis is honest: readability/contrast/transparency, density mismatch, vestibular/motion risk, responsive fragility, font payload/licensing, filter/3D cost, implementation+design-system divergence.
8. Rendering comparison under identical evidence conditions when capability exists (same viewport(s)/copy/state/controls); perceptual stress tests applied from verification module definitions.
9. Selection logic balances product fit/comprehension/interaction/a11y/coherence/responsive/performance/identity/cost — but one disqualifying risk beats any aggregate. Recommend a winner and the dominant trade-off ("it depends" only when missing preference materially changes product).
10. After selection refine chosen dimensions; do not silently create V4 by casual hybridization of rejected options.

Output contracts: DNA sections written to IR + design-dna.json. Counter-default recorded (the nearest generic pattern deliberately refused).
