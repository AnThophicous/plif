# Create slide deck

Use whenever the user asks for a presentation, pitch deck, slideshow, or slide
file. Treat this as a requirements and evidence workflow, not a template fill.

1. Resolve audience, purpose, length, format, sources, and visual direction.
2. Research only from supplied or verified sources. Never invent facts, numbers,
   quotes, case studies, or placeholder data presented as real.
3. Produce an outline and obtain approval before writing final slide content.
4. Define a visual system, then specify hierarchy, layout, and evidence for
   every slide.
5. Hand finished content and design decisions to `office-render`.
6. Validate the generated file and inspect the rendered result before reporting
   success. If a renderer or source is missing, state that explicitly.

Use `context-ingestion` for already-extracted heterogeneous sources before
making narrative or design decisions. Own the story and design here; do not
delegate those decisions to the rendering layer.
