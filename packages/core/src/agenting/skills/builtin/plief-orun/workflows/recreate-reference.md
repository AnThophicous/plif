# Recreate a Visual Reference

Treat screenshots, videos, Awwwards sites, Framer projects and external websites as
visual/behavior references unless portable source is legitimately provided.

Decompose:
`LAYOUT / TYPOGRAPHY / COLOR / SURFACES / COMPONENTS / MOTION / SCROLL / MICROINTERACTIONS / 3D / RESPONSIVE`

Then:
1. identify invariant visual behaviors;
2. search concepts/candidates;
3. decide what can be reused legitimately;
4. reconstruct original implementation in the project's stack;
5. compare against reference at target breakpoints;
6. do not claim invisible implementation details as facts.
