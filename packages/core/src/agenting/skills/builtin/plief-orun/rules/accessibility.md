# Accessibility Gate

Every implementation considers:
- semantics before ARIA
- keyboard operation
- focus order and visible focus
- screen-reader names/states
- touch targets and touch parity
- contrast
- reduced motion
- non-motion access to information
- carousel/modal/menu escape and focus behavior where applicable

Motion that communicates state must retain equivalent meaning when reduced.
Do not approve a visually impressive interaction that becomes unusable by keyboard or touch.
