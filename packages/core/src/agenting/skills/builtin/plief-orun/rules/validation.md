# Final Quality Gate

Before completion:
1. external names/commands/imports are real and current enough;
2. library choice matches the need;
3. dependency cost is justified;
4. design system is preserved or intentionally changed;
5. mobile/tablet/desktop are considered;
6. keyboard/touch/reduced-motion are considered;
7. runtime lifecycle and cleanup are correct;
8. premium/reference content is handled legally;
9. relevant tests/build/runtime/visual checks were executed or explicitly unavailable;
10. a simpler solution would not provide equal quality.

If a critical answer is no, keep working.
