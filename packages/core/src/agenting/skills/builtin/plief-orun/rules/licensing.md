# Licensing and Premium Content

Metadata about premium items may be indexed.
Unauthorized premium source code may not be stored or reproduced.

For paid items:
`availability: premium`
`source_code_available: authorized_access_required`

Allowed:
- recommend
- explain behavior
- point to official acquisition/install path
- integrate code/files the user legitimately provides
- create an original implementation inspired by behavior, without copying protected code

If reuse terms are unclear, mark `UNVERIFIED` and avoid asserting commercial permission.
