# Implementation Rules

1. Prefer existing project technology when it can meet the requirement.
2. Verify external items before install.
3. Install the smallest sufficient dependency set.
4. Inspect generated files; registry installation is not proof of correctness.
5. Adapt to local aliases and tokens.
6. Preserve client/server boundaries.
7. Avoid duplicate animation engines for the same concern.
8. Add cleanup and reduced-motion paths.
9. Test the interaction, not merely compilation.
10. Never copy protected premium code without legitimate user-provided access.
