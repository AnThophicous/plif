## Current reality
Origin UI must be treated as a **legacy lineage**, not as a timeless active registry.
The official coss roadmap says coss ui is the evolution of Origin UI, and the repository
retains `apps/origin` as a legacy pre-acquisition snapshot with limited maintenance.

When a user asks for "Origin UI":
1. decide whether they explicitly mean the legacy collection;
2. if yes, search `https://coss.com/origin`;
