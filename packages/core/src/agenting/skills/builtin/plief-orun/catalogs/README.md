# Canonical Memory

These files are **strategic bootstrap data**, not a frozen mirror of the internet.

- `sources.json`: normalized source profiles and evidence.
- `items.json`: selected high-value verified seed items.
- `concepts.json`: canonical intent concepts.
- `relationships.json`: knowledge-graph edges.

Long-tail knowledge is discovered JIT and may be persisted only after authoritative
verification and schema validation.

Authority remains:

`OFFICIAL SOURCE > LOCAL INDEX > MODEL MEMORY`

The `indexes/` directory is compiled/disposable and must never override canonical data.
