# Native Terminal Scroll Only Implementation Plan

> **For agentic workers:** Execute inline in this session. Do not commit unless the user separately authorizes it.

**Goal:** Remove every Plif-controlled scrolling path and leave history navigation entirely to the terminal.

**Architecture:** Ink continues rendering the live frame and committing settled transcript rows to `<Static>`, but Plif no longer captures mouse-wheel input or maintains a virtual viewport. The terminal owns wheel scrolling, selection, scrollback position, and whether new output is followed.

**Tech Stack:** TypeScript, React, Ink, Node.js test runner.

## Global Constraints

- Keep `Ctrl+T` as the keyboard control for the WorkDock.
- Do not capture mouse input or wheel events.
- Do not expose virtual follow state, offsets, or snap-to-bottom actions.
- Preserve the native terminal scrollback generated by Ink `<Static>`.
- Do not commit without separate user authorization.
